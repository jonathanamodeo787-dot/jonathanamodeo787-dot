## ⛏️ WebMine

<a href="https://jonathanamodeo787-dot.github.io/Webmine/bloques.html">
<img width="50" src="https://cdn-icons-png.flaticon.com/512/164/164756.png">
</a>

**WebMine** es una wiki interactiva de Minecraft desarrollada con:

- HTML
- CSS
- JavaScript
- JSON

Características:

✅ Wiki de bloques de Minecraft  
✅ Sistema de búsqueda dinámica  
✅ Carga de datos mediante Fetch API  
✅ Información organizada en archivos JSON  
✅ Categorías de bloques  
✅ Diseño oscuro estilo wiki  
✅ Interfaz responsive  


🌐 Demo:

https://jonathanamodeo787-dot.github.io/Webmine/bloques.html
